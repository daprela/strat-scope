# Normative rule disposition — v1.0

Date: 2026-10-10. **105/105 audited authoring obligations receive an explicit format rule, scoped producer/reader obligation, or explicit exclusion.** This is authoring coverage, not a claim that every reader obligation has an implemented production test. Contract section numbers refer to the authored backtest-data-format.md. Named tests are in test_conformance.py; schemas and reference evidence are colocated.

The full validator checks the supplied base schemas, known section bytes, relationships, lifecycle, scalar rules and complete index coverage. Unknown optional internals remain opaque. Historical knowledge truth, financial-result accuracy, connectedness and actual publication durability require producer documentation/evidence. Discovery, full scoped qualification, transport, market matching, diagnostic containment and rendering are specified reader obligations whose production realization remains pending. No missing old behavior is silently promoted into the first release.
